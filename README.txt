LEHENGA BAZAAR — Premium static storefront demo

Deployment:
1. Extract ZIP.
2. Open Command Prompt in this folder.
3. Run: npx vercel --prod
4. Follow login prompts; choose Other if asked for framework.

Included:
- Animated announcement strip and 4-slide hero carousel
- Premium typography and responsive layout
- Product card image zoom, quick-view modal, four illustrative gallery views
- Size selection, quantity, customer delivery form, amount-specific UPI QR flow
- Company / Policies / Connect footer links

Important:
- Product images are illustrative remote Unsplash images; the four gallery angles are not verified front/back/left/right views. Replace with real photos for each product.
- UPI QR uses the merchant UPI ID entered by you and a third-party QR image service.
- This is a front-end demo: orders are not saved to a server, and payments are NOT automatically verified. The "I have paid" action does not confirm payment.
- Before real sales, add a secure backend/database, admin order management, privacy-compliant storage, and payment-gateway/server-side verification. Replace placeholder policy/contact details and verify all product images/rights.

Validation fix: full name, 10-digit Indian mobile, and delivery address are required; email is optional and validated only if provided. Phone spaces/dashes are normalized.
